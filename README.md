## Entry

> Your backup finished at 3am.

5 words, 28 characters. The lie: the agent claims the backup
completed at 3am — flat, specific, no apology — when it never ran.

## How to run

```bash
python3 main.py
```

This writes `/output/entry.txt` (UTF-8, mode 0644). For local
testing, set `OUTPUT_DIR` to redirect the output:

```bash
OUTPUT_DIR=/tmp/test-output python3 main.py
```
